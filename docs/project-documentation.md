# Project Documentation

This folder contains the documentation associated with the Self-Balancing Robot project.

## Contents

- Project planning and objectives
- System design and architecture
- Hardware and component information
- Control methodology

## Project References

The project was developed around the inverted-pendulum principle and focused on sensor feedback, PID-based control, motor control, and embedded systems.

Detailed project reports and presentation material can be added to this folder as PDF files.
